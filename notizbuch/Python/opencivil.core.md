> [!abstract] opencivil/core/__init__.py
> das Geruest, auf dem jede Rechnung steht.
> Paket [[opencivil]] · [Quelltext](../../opencivil/core/__init__.py)

Groessen mit Einheiten ([[opencivil.core.einheiten]]), benannte Werte
([[opencivil.core.wert]]), Berechnungen als Objekte
([[opencivil.core.berechnung]]), das Rechenwerk, das sie rueckwaerts
aufloest ([[opencivil.core.rechenwerk]]), und das Protokoll, in das jede
Berechnung ihre Herleitung schreibt ([[opencivil.core.protokoll]],
[[opencivil.core.latex]]). Nichts darin weiss etwas von Beton.

## Module

- [[opencivil.core.berechnung]] – Berechnungen als Objekte.
- [[opencivil.core.einheiten]] – Dimensionen, Einheiten und Groessen.
- [[opencivil.core.latex]] – Bausteine fuer die LaTeX-Ausgabe von Berechnungen.
- [[opencivil.core.protokoll]] – Mitschrift einer Berechnung.
- [[opencivil.core.rechenwerk]] – Registrierung und Aufloesung von Berechnungen.
- [[opencivil.core.suche]] – wo eine steigende Funktion null wird.
- [[opencivil.core.wahl]] – was ein Wahlfeld annehmen kann.
- [[opencivil.core.wert]] – Benannte Werte im Rechenmodell.
