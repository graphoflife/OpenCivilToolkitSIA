## VERANTWORTUNG

Schreibt die Seiten des Ordners `notizbuch/`, die aus dem Code entstehen:
je Formel eine Seite, je Thema eine, je Modul eine. Obsidian liest den Ordner
als Tresor, die Oberflaeche zeigt ihn unter «Formelsammlung». Die Seiten
schreibt `python3 -m opencivil.web.bruecke`; was von Hand dazukommt -- die
Theorie unter der Linie, eigene Notizen --, bleibt dabei stehen.

## Module

- [[opencivil.notizbuch.bibliothek]] – die Python-Bibliothek als Seiten.
- [[opencivil.notizbuch.erzeugen]] – alle Seiten, die aus dem Code entstehen.
- [[opencivil.notizbuch.formelseiten]] – die Formelsammlung als Seiten.
- [[opencivil.notizbuch.namen]] – aus einem Namen wird ein Seitenname.
- [[opencivil.notizbuch.tresor]] – erzeugte Seiten in den Ordner `notizbuch/`.
